# スクショ寄せ装飾アセット計画

## 目的

参考スクショの「木製ボード上のおもちゃ」「明るい室内」「下から出てくる白い回答シート」に寄せる。ゲームロジック、ドラッグ判定、回答状態は増やさず、装飾は非操作レイヤーとして追加する。

## 現存素材の棚卸し

- 赤いドロップキャラ
  - `src/assets/characters/generated/frames/`
  - `src/assets/characters/generated/sprites/`
  - `thinking`, `wrong`, `correct`, `praise` のPNGフレームとスプライトシートは既にある。
- ゼリー本体
  - 現在は `src/styles/global.css` のCSS描画。
  - 光沢、影、色分けは十分使えるため、追加ラスター化は不要。
- 皿/トレイ
  - 現在は `.source-group` のCSS描画。
  - 参考スクショの淡い緑の縁、空スロット、厚みには追加CSSが必要。
- 下部HUD/回答シート
  - `.bottom-hud`, `.jelly-progress-meter`, `.answer-area` は実装済み。
  - 白い丸い底面と床への埋め込み感をもう一段足せる。
- `public`
  - `jelly-icon.svg` のみ。ゲーム背景用の木目、窓、棚、カップ装飾は未整備。
- `docs/ui-proposals`
  - `bottom-sheet-progress-final.png` は方向性確認用。ランタイム背景としてそのまま使わず、分解リファレンスにする。

## 足りない素材

優先度順に追加する。

1. 木製ボード/机面
   - 形式: 小さなWebP反復タイル、またはCSSグラデーション強化。
   - 目安: 256pxから512px、40KB以内。
   - 用途: `.game-screen::before` の背景レイヤー。

2. 窓と外景
   - 形式: SVG推奨。
   - 内容: 角丸窓、青空、雲、丘。
   - 用途: 右上の非操作装飾。`aria-hidden`, `pointer-events: none`。

3. 左右のゼリーカップ/棚
   - 形式: SVGまたは透明WebP。
   - 内容: ピンク、青、緑、黄色のカップを左右端に少量。
   - 用途: 画面端の奥行きづくり。ゲーム盤面やボタンに重ねない。

4. トレイの空スロット
   - 形式: CSS優先。必要なら `tray-slot.svg`。
   - 内容: 5列2段の薄い凹み、縁のハイライト、内側の影。
   - 用途: `.plate-jellies::before` などで、ゼリーの下にだけ敷く。

5. 白い底面シートのふくらみ
   - 形式: CSS疑似要素優先。
   - 内容: 回答シート下部に大きな白い丸みと淡い青/ピンクの反射。
   - 用途: `.answer-area::after` または `.answer-sheet-slot::after`。

6. 木製メニューボタンと矢印の質感
   - 形式: CSS/SVG。
   - 内容: 参考スクショの丸い木製メニュー、立体的な移動矢印。
   - 用途: 既存 `ParentMenuHandle` と `.source-transfer` の見た目改善。

## 実装方針

- 装飾用DOMは `GameScreen` の背景レイヤーにまとめ、ゲーム操作要素とは分離する。
- 追加DOMは原則 `aria-hidden="true"` と `pointer-events: none`。
- フルスクリーンPNGを避け、CSS/SVG中心にする。
- ラスターが必要な場合だけ `imagegen` で木目タイルやカップ装飾を生成する。
- 追加アセット合計はまず300KBから500KB以内を目標にする。
- 既存の赤いドロップキャラは置き換えない。配置と影だけ調整する。

## 次の作業計画

1. `GameScreen` に `scene-decoration` レイヤーを追加する。
   - 木製ボード、窓、左右カップをここに置く。
   - 操作判定に影響しないことを確認する。

2. CSSだけで机面と窓の初期版を作る。
   - まずラスターなしで全体の構図を合わせる。
   - 844x390, 667x375, 960x540でプレートと回答シートに重ならないか見る。

3. トレイ表現を強化する。
   - 空スロット、淡い緑の縁、底面影を追加する。
   - ゼリーのgridサイズとドラッグヒット判定は変えない。

4. 回答シートの底面をスクショ風にする。
   - 白いふくらみ、上部ハンドル、柔らかい影を調整する。
   - シート上端は短い横画面でもプレート下に留める。

5. 不足するラスター素材だけ生成する。
   - 木目タイル。
   - 左右カップ装飾。
   - 必要なら淡い窓外背景。

6. 装飾込みの視覚確認を行う。
   - `npm run lint`
   - `npm run build`
   - 横向きスマホ相当のスクショ確認。
   - reduced-motion時に装飾が動きすぎないことを確認する。

## 受け入れ基準

- 参考スクショの木製ボード、窓、カップ、白い底面シートの方向性が第一画面で伝わる。
- ゼリー、式、回答ボタン、キャラが装飾に埋もれない。
- 装飾がドラッグ、長押しメニュー、回答ボタンの操作を邪魔しない。
- 追加依存、UIフレームワーク、ゲームエンジンを入れない。
- 低い横画面でも回答シートがプレート領域に侵入しない。
