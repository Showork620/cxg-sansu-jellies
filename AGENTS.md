# Agent Instructions

## UI And Game Design Skill Priority

This project is a lightweight React/Vite preschool math game. For UI, UX, and visual design work here, prefer the most project-specific skills first:

1. Use `game-ui-design` as the primary design skill for game screen layout, feedback, HUD-like elements, onboarding/play flow, motion meaning, and touch-first interaction.
2. Use `vercel-react-best-practices` when UI work touches React component structure, render frequency, pointer/drag behavior, bundle size, or performance.
3. Use `imagegen` for raster character, background, sprite, or visual asset generation.
4. Use `ui-ux-pro-max` only as a supplemental reference for targeted child-friendly color, typography, accessibility, or tactile UI ideas. Do not use its broad `--design-system` output as the source of truth for this game, and ignore landing-page, SaaS, dashboard, social-proof, or marketing-page recommendations.

Avoid adding UI frameworks, Tailwind, shadcn/ui, heavy animation libraries, or game engines unless the user explicitly asks. Keep the game lightweight, touch-first, large-type, preschool-safe, and friendly to reduced-motion users.
